# AMARASINGHE HARDWARE MANAGEMENT SYSTEM - AI CONTEXT
*To the AI: Read these rules before generating any code for this project.*

## 1. Project Architecture
* **Framework:** WPF (Windows Presentation Foundation) using .NET Framework 4.7.2.
* **Language:** C# and XAML.
* **UI Pattern:** Code-behind (We are NOT using strict MVVM right now to keep it simple for the team).
* **Styling:** Modern, dark/light themes, flat borders, high contrast. No drag-and-drop Windows Forms code!

## 2. Database Standards
* **Database Name:** `AmarasingheHardwareDB` (SQL Server)
* **Connection String:** Stored in `App.config` as `HardwareDBConnection`.
* **Connection Class:** Managed via `HardwareManagementSystem.Database.DbConnection.GetConnection()`. 
* **Staff Table Schema:** `StaffID`, `FullName`, `NIC`, `Phone`, `Username`, `PasswordHash`, `Role`, `Salary`, `StartingDate`, `Age`, `IsActive`.

## 3. UI Naming Conventions (Crucial!)
When generating XAML, always use standard camelCase prefixes for x:Name:
* TextBoxes: `txt[Name]` (e.g., `txtUsername`)
* Buttons: `btn[Name]` (e.g., `btnLogin`)
* Labels/TextBlocks: `lbl[Name]`
* DataGrids: `dg[Name]`
* ComboBoxes: `cmb[Name]`

## 4. Current State
* **Completed:** WPF Migration, Database Connection, Login UI (`MainWindow.xaml`), Login Backend logic with Role-based routing (Manager vs. Cashier).
Class: StaffManagement (The Main Dashboard Screen)
dgStaff: The main DataGrid table. We use this in C# to display the list of database rows and to figure out which user row was clicked.

btnAddStaff: The green button. Clicks trigger the empty pop-up to add a new user.

btnUpdateStaff: The orange button. Clicks trigger the pop-up and send it the dgStaff's currently selected row.

btnDeleteStaff: The red button. Clicks will eventually trigger a SQL DELETE query.

txtSearch: The grey search bar. We use this to grab the text the user types (e.g., "Manager") to filter the grid.

btnSearch: The button that executes the search filter using the text from txtSearch.

Class: StaffDetailsWindow (The Pop-Up Data Entry Form)
txtFullName: TextBox to type or read the staff member's full name.

txtNIC: TextBox for the National Identity Card number.

txtPhone: TextBox for the phone number.

txtUsername: TextBox for the system login username.

txtPassword: A special PasswordBox that hides the characters with dots when the user types their login password.

cmbRole: The ComboBox (Dropdown). We use this to grab the selected role (Manager, Cashier, Admin).

txtSalary: TextBox for the numeric salary amount.

txtAge: TextBox for the numeric age.

dpStartingDate: The DatePicker control. We use this to grab the exact calendar date selected.

chkIsActive: The CheckBox. We use this to check if it's True (active account) or False (disabled account).

btnSave: The main green save button. Clicking this will trigger the database INSERT or UPDATE query.

btnCancel: The grey cancel button. Closes the pop-up without doing anything.
